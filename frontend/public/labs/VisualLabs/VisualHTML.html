📖 Guia Rápido de Tags HTML e Regras CSS
Sintaxe / Propriedade Função / O que Faz Aplicação Prática Exemplo de Código
<div> Bloco genérico de divisão / contêiner de elementos Agrupar textos, botões e imagens. <div class="card">...</div>
padding vs margin Espaçamento interno (padding) vs externo (margin) Dar respiro ao conteúdo ou afastar caixas. padding: 20px; margin-bottom: 10px;
display: flex Ativa o modelo de layout flexível unidimensional Alinhar itens em linha ou coluna. display: flex; gap: 15px;
display: grid Ativa o modelo de grid bidimensional (linhas e colunas) Criar dashboards e galerias complexas. grid-template-columns: 1fr 1fr;
position: absolute Posiciona um elemento em relação ao pai relative Criar badges fixas nos cantos de cartões. top: -10px; right: 10px;
box-shadow Aplica sombras externas ou brilhos neon Dar profundidade visual e efeitos de brilho. box-shadow: 0 0 15px #a855f7;
:hover Pseudo-classe para acionar estilos ao passar o mouse Mudar cores, botões e aplicar animações. .btn:hover { transform: scale(1.05); }
transition Suaviza a transformação entre estados CSS Evitar mudanças bruscas ao passar o mouse. transition: all 0.3s ease;
