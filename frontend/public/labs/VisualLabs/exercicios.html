Resumo dos Formatos

JSON

Baseado em chave-valor e listas. Usa {} para objetos e [] para arrays. Aspas duplas obrigatórias nas chaves.

XML

Baseado em tags personalizadas <tag>conteudo</tag>. Exige uma tag raiz única envolvendo todo o documento.

CSV

Formato de texto simples para tabelas. Dados separados por vírgula (ou ponto e vírgula), onde cada linha representa um registro.
