Bash Shell Fundamentals

Guia Prático de Navegação, Manipulação de Arquivos e Shell Script para Iniciantes

💻 1. O que é o Bash e seu Funcionamento

O Bash (Bourne Again SHell) é o interpretador de comandos padrão na maioria das distribuições Linux e macOS. Ele opera como uma interface baseada em texto (CLI) que processa instruções digitadas e se comunica com o Kernel do sistema operacional, permitindo navegar por diretórios, executar utilitários e criar scripts de automação.

1
Diretório Atual e Caminhos: O sistema organiza arquivos em árvore. Caminhos relativos iniciam da pasta atual (./), enquanto caminhos absolutos iniciam da raiz (/).
2
Streams de Entrada/Saída: O Bash opera com stdin (entrada padrão: 0), stdout (saída padrão: 1) e stderr (saída de erros: 2).
3
Encadeamento com Pipes (|): Permite conectar a saída (stdout) de um comando diretamente na entrada (stdin) do próximo.
📁 2. Navegação pelo Sistema e Gestão de Arquivos

Estes são os comandos fundamentais de movimentação, listagem e alteração da estrutura do disco local.

Comando Sintaxe Básica Descrição e Aplicação
pwd pwd Exibe o caminho do diretório de trabalho atual (*Print Working Directory*).
ls ls -la Lista os arquivos e pastas do diretório. A flag -l mostra detalhes (permissões, tamanho) e -a exibe arquivos ocultos.
cd cd /pasta/subpasta Navega entre diretórios. Use cd .. para voltar um nível ou cd ~ para ir à home do usuário.
mkdir mkdir -p projetos/app Cria novos diretórios. A flag -p cria pastas pai inexistentes em subníveis.
touch touch script.sh Cria um arquivo vazio ou atualiza o timestamp de modificação de um arquivo existente.
cp cp -r orig/ dest/ Copia arquivos. Use a flag -r (*recursive*) para copiar pastas completas.
mv mv arq.txt novo.txt Move ou renomeia arquivos e diretórios de um local para outro.
rm rm -rf pasta/ Remove arquivos. A combinação de flags -rf força a remoção recursiva sem pedir confirmação.
📝 3. Leitura, Filtros e Redirecionamento

Exemplos práticos de leitura de arquivos no terminal e envio de resultados para novos documentos usando redirecionadores (> e >>).

# 1. Exibir todo o conteúdo de um arquivo no console user@linux:~$ cat /etc/os-release # 2. Ler apenas as primeiras 5 linhas de um log user@linux:~$ head -n 5 server.log # 3. Monitorar alterações de um arquivo de log em tempo real user@linux:~$ tail -f /var/log/syslog # 4. Buscar por uma palavra específica usando grep user@linux:~$ grep -i "error" app.log # 5. Criar um novo arquivo redirecionando a saída (sobrescreve o conteúdo) user@linux:~$ echo "Servidor Inicializado" > status.txt # 6. Adicionar conteúdo ao final de um arquivo existente (append) user@linux:~$ echo "Conexão BD OK" >> status.txt # 7. Usar o Pipe (|) para contar o número de processos do Node rodando user@linux:~$ ps aux | grep node | wc -l
🔒 4. Gestão de Permissões (chmod e chown)

No modelo POSIX do Linux, cada arquivo tem 3 níveis de acesso: **Usuário Dono (u)**, **Grupo (g)** e **Outros (o)**, divididos em **Leitura (r=4)**, **Escrita (w=2)** e **Execução (x=1)**.

# Tornar um script de shell executável (+x) user@linux:~$ chmod +x deploy.sh # Aplicar permissão 755 (Dono: rwx | Grupo: r-x | Outros: r-x) user@linux:~$ chmod 755 script.sh # Alterar o dono e o grupo do arquivo user@linux:~$ sudo chown www-data:www-data /var/www/html/index.html
⚙️ 5. Exemplo de Script Bash (.sh) com Condicionais

Os scripts em Bash iniciam obrigatoriamente com a linha Shebang (#!/bin/bash), que define o interpretador do arquivo.

#!/bin/bash # Definição de Variáveis APP_DIR="/var/www/meu-app" LOG_FILE="./deploy.log" echo "=== Iniciando Verificação do Ambiente ===" # Estrutura Condicional (If/Else) if [ -d "$APP_DIR" ]; then echo "[OK] O diretório $APP_DIR existe." >> "$LOG_FILE" else echo "[ALERTA] Diretório não encontrado. Criando..." mkdir -p "$APP_DIR" fi echo "Processo finalizado com sucesso."
