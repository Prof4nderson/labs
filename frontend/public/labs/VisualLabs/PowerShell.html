PowerShell Fundamentals

Cmdlets, Manipulação de Objetos, Pipeline e Scripts para Iniciantes

⚡ 1. O que é o PowerShell e seu Funcionamento Baseado em Objetos

O PowerShell é um shell de linha de comando e linguagem de script desenvolvida pela Microsoft (atualmente cross-platform via .NET Core). Diferente do Bash/CMD que operam manipulando texto puro, o PowerShell opera inteiramente manipulando Objetos .NET.

1
Padrão Verbo-Substantivo: Os comandos (chamados de Cmdlets) usam estritamente o formato Verbo-Substantivo (ex: Get-Process, New-Item, Set-ExecutionPolicy).
2
Pipeline Orientado a Objetos (|): Ao passar dados pela pipeline, o PowerShell transmite objetos estruturados contendo propriedades e métodos nativos, sem necessidade de parsers complexos de texto.
3
Aliasing Integrado: Mapeia comandos clássicos do Linux/CMD para Cmdlets equivalentes (ex: ls e dir apontam internamente para Get-ChildItem).
🔷 2. Principal Tabela de Cmdlets Básicos

Comandos essenciais para navegação no sistema de arquivos, gestão de serviços e controle de processos.

Cmdlet Nativo Alias (Linux / CMD) Descrição e Função
Get-Location pwd Retorna o objeto correspondente ao diretório de trabalho atual.
Get-ChildItem ls / dir Lista itens e contêineres do diretório ativo.
Set-Location cd Altera o diretório ativo para o caminho especificado.
New-Item mkdir / touch Cria novos elementos (arquivos com -ItemType File ou pastas com -ItemType Directory).
Copy-Item cp / copy Copia itens de uma origem para um destino especificado.
Remove-Item rm / del Remove arquivos, diretórios ou chaves do registro do Windows.
Get-Content cat / type Lê o conteúdo de arquivos de texto linha a linha.
Get-Process ps / tasklist Obtém a lista de todos os processos em execução no sistema.
⚙️ 3. Manipulação de Objetos com Where-Object e Select-Object

Diferente do texto puro, podemos filtrar propriedades diretas de objetos retornados usando o operador de comparação do PowerShell (-eq, -match, -gt).

# 1. Listar processos que consomem mais de 100MB de memória de trabalho (WorkingSet) PS C:\> Get-Process | Where-Object { $_.WorkingSet64 -gt 100MB } # 2. Selecionar apenas as propriedades especificas (Nome e ID) de processos do Chrome PS C:\> Get-Process chrome | Select-Object Name, Id, CPU # 3. Ordenar arquivos por tamanho em ordem decrescente PS C:\> Get-ChildItem | Sort-Object Length -Descending # 4. Buscar por um texto dentro de arquivos em subpastas PS C:\> Get-ChildItem -Recurse -Filter *.log | Select-String -Pattern "Error"
🛡️ 4. Política de Execução de Scripts (ExecutionPolicy)

Por padrão, o Windows bloqueia a execução de scripts não assinados (.ps1). Para permitir a execução de scripts locais no seu usuário de desenvolvimento, configure a política para RemoteSigned.

# Consultar a política de execução atual PS C:\> Get-ExecutionPolicy # Permitir scripts locais (Executar como Administrador) PS C:\> Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
📂 5. Exemplo de Script PowerShell (.ps1)

Script declarativo utilizando variáveis com $, tratamento de exceções com blocos try/catch e saídas coloridas com Write-Host.

# Script de Backup Automático em PowerShell $sourcePath = "C:\Projetos\App" $destinationPath = "C:\Backups" $date = Get-Date -Format "yyyy-MM-dd" Write-Host "Iniciando Backup do Projeto..." -ForegroundColor Cyan if (-not (Test-Path $destinationPath)) { New-Item -Path $destinationPath -ItemType Directory } try { Copy-Item -Path $sourcePath -Destination "$destinationPath\Backup_$date" -Recurse -ErrorAction Stop Write-Host "[SUCESSO] Backup concluído com êxito!" -ForegroundColor Green } catch { Write-Host "[ERRO] Falha ao realizar backup: $_" -ForegroundColor Red }
