Lista de Desejos — versão HTML / CSS / JavaScript puro
=====================================================

Arquivos:
  index.html   estrutura da página
  styles.css   tema glass + dark fluorescente
  config.js    <-- EDITE APENAS ESTE ARQUIVO
  app.js       monta os cards a partir do config.js
  fotos/       coloque suas imagens aqui (opcional)

Como usar:
  1. Abra config.js e mude títulos, rodapé, cor neon (cyan | lime | violet | pink)
     e a lista de itens (title, description, image, tag, link).
  2. Para usar fotos locais, salve em fotos/ e use image: "fotos/minha-foto.jpg".
  3. Abra index.html no navegador (duplo clique) — não precisa instalar nada.

Publicar: envie todos os arquivos para qualquer hospedagem estática
(Netlify, Vercel, GitHub Pages, hospedagem comum via FTP).
